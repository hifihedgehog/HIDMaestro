HIDMaestro third-party notices
==============================

HIDMaestro includes the following third-party material. This notice is
embedded in HIDMaestro.Core.dll and written to disk alongside usbip-win2
whenever HIDMaestro deploys it.

--------------------------------------------------------------------
usbip-win2 (version 0.9.8.1)
https://github.com/vadimgrn/usbip-win2
--------------------------------------------------------------------

Used as the USB transport for HIDMaestro's composite USB personas
(profiles that present USB Audio Class interfaces alongside HID). A
Windows audio endpoint requires a driver-backed USB device, which no
user-mode API can create, so HIDMaestro speaks the USB/IP protocol to
usbip-win2's virtual host controller. Every device behavior remains in
HIDMaestro's own user-mode code.

The redistributed binaries are usbip-win2's own signed host controller
driver, unmodified: usbip2_ude.inf, usbip2_ude.sys and usbip2_ude.cat,
unpacked at build time from usbip-win2's signed installers. The x64 files
come from the v.0.9.8.1 release asset. The ARM64 files come from the same
tag's build that the project's signing service (ossign.org) published in
usbip-win2 issue #13, with drivers attestation-signed by Microsoft.
HIDMaestro installs the one matching the machine's architecture. It does
not redistribute the installers or the root-hub filter driver.

DsHidMini
https://github.com/nefarius/DsHidMini
--------------------------------------------------------------------

The dualshock-3-full profile reproduces the HID report descriptor that
DsHidMini presents in its SXS mode (driver/HID/03_SXS_Col1_Joystick.h),
and HIDMaestro's driver derives that mode's input and feature reports
from the native DualShock 3 report the way DsHidMini does.
